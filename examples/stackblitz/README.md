# StackBlitz example

A minimal standalone Angular app that installs **`@inandu-solutions/grid-angular`** from npm
and renders a `<inandu-grid>` with sorting, per-column filters, grouping, selection, the
column-toggle popup, aggregates / totals, and the export toolbar.

**Open it live (no account needed):**
<https://stackblitz.com/github/inandusolutions/inandu-grid/tree/main/examples/stackblitz>

Run it locally:

```bash
cd examples/stackblitz
npm install
npm start        # http://localhost:4200
```

The whole example is `src/app/app.component.ts` — edit it and the grid updates live.
