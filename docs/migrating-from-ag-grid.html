Migrating from AG Grid to inandu-grid

A factual, side-by-side comparison for Angular apps moving off AG Grid's Community or Enterprise tier onto the MIT-licensed @inandu-solutions/grid-angular. Feature equivalents first, then what's genuinely different, so there are no surprises after you switch.

Try the live demo Read the full manual View on npm
Why teams migrate Row grouping, aggregates, Excel-compatible export and cell-range selection sit behind AG Grid's paid Enterprise licence. The same capabilities are free (MIT) in inandu-grid. If your app relies on AG Grid Enterprise's pivot table or integrated charts, inandu-grid does not have those — see what's different below before you commit to migrating.

AG Grid's config-object style:

columnDefs = [
  { field: 'name', headerName: 'Name', sortable: true },
  { field: 'age', headerName: 'Age', sortable: true, filter: 'agNumberColumnFilter' },
];
rowData = people;

becomes inandu-grid's declarative template style:

<inandu-grid [data]="people" filter="true">
  <inandu-column field="name" title="Name" sortable="true" />
  <inandu-column field="age" title="Age" type="number" sortable="true" filter="yes" />
</inandu-grid>

What's different

inandu-grid is deliberately not a kitchen sink. Being honest about the gaps up front is cheaper than finding them mid-migration:

  • No pivot table. AG Grid Enterprise's pivot mode has no inandu-grid equivalent.
  • No integrated charts. Wire your own chart library (Chart.js, ECharts, …) off the same row data instead.
  • Angular only. AG Grid ships framework wrappers for React/Vue/vanilla too; inandu-grid's sibling project is inandu-grid-react for React, with its own separate API.
  • Native .xlsx (styled, binary) is a paid @inandu-solutions/grid-pro feature, same as AG Grid Enterprise's Excel export — the free tier in both projects covers CSV, and inandu-grid's free tier additionally covers a plain .xls.

Migration checklist

  • Replace ag-grid-angular/ag-grid-community/ag-grid-enterprise with ng add @inandu-solutions/grid-angular.
  • Turn each columnDefs entry into an <inandu-column> element using the table above.
  • Move Enterprise-gated features (grouping, aggregates, range selection, Excel export, server-side rows, tree data) over — they're free here, so no licence to remove or replace.
  • If you use AG Grid's pivot mode or integrated charts, plan a separate solution — they have no equivalent (see above).
  • Run your existing component tests against the new template — inandu-grid never mutates your data array itself, same contract as AG Grid's row-data model.
